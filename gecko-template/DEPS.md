# Gecko template — external dependencies (DEPS)

`build_gecko_template.sh` does **not** download its binary
dependencies. It references them in place from the Phase 0 / Phase 2
working directories, and those binaries are **not** included in this
repository snapshot (same convention as the regular edition's
launcher PNGs, `apksig-only.jar` and the embedded `template.apk`
asset). To rebuild the Gecko template, fetch and place them manually
as below first.

## 1. GeckoView 159

- Artifact: `org.mozilla.geckoview:geckoview:159.0.20261102144711` (AAR, arm64-v8a)
- Source: Mozilla Maven — `https://maven.mozilla.org/maven2/org/mozilla/geckoview/geckoview/`
  (version listing: `.../geckoview/maven-metadata.xml`)
- Placement expected by the build script:
  - Extracted AAR contents in `gecko-spike/deps/gv/`
    (`AndroidManifest.xml`, `classes.jar`, `res/`, `assets/omni.ja`, `jni/`, …)
  - The AAR itself kept as `gecko-spike/deps/geckoview-159.0.20261102144711.aar`
- Transitive POM bundle: GeckoView's POM dependencies must be
  bundled completely (follow the POM transitively — a partial bundle
  crashes at startup). The device-proven bundle lives in
  `gecko-spike/deps/downloads-diag/` (downloaded AARs/jars, incl.
  `lifecycle-process-2.11.0.aar`) and `gecko-spike/deps/extra-diag/`
  (extracted `*-classes.jar` files for androidx.core,
  androidx.lifecycle, androidx.startup, etc.). Library R classes are
  generated by the build script via
  `aapt2 link --extra-packages` — do not skip that step.

## 2. UnifiedPush connector 3.3.5

- Artifact: `org.unifiedpush.android:connector:3.3.5` (AAR)
- Source: Maven Central
- Placement expected by the build script:
  - AAR at `gecko-push/deps/up/connector-3.3.5.aar`
  - Extracted AAR at `gecko-push/deps/up/x/` (the build uses
    `gecko-push/deps/up/x/classes.jar` on the kotlinc classpath)

## 3. Tink 1.23.0

- Artifact: `com.google.crypto.tink:tink:1.23.0` (jar) — the
  connector POM's declared runtime dependency; the connector's
  vendored Web Push decryption references Tink's `subtle/*` classes.
- Source: Maven Central
- Placement expected by the build script:
  - Jar at `gecko-push/deps/tink-1.23.0.jar`

## Notes

- Exact versions matter: the build recipe (manifest merging,
  R-class generation, multi-dex packaging) was device-verified with
  precisely the versions above.
- No dependency binary (`.aar` / `.jar`) is staged in this
  repository; only this note and the build script describe them.
